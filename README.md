# GB Industrial & Medical Gases

A production-ready Vite and Tailwind CSS foundation for the future GB Industrial & Medical Gases B2B website.

## Technology Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Vite
- npm

This project intentionally has no React, Bootstrap, backend, company claims, or placeholder business data.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Project Structure

```text
index.html                 Homepage entry point
pages/                     Static HTML page entry points
assets/                    Images, icons, and logo directories
css/                       Tailwind entry stylesheet
js/                        Modular vanilla JavaScript files
components/                Static component placeholders for future integration
documents/                 Certificates and brochures directories
vite.config.js             Vite and multi-page build configuration
package.json               npm scripts and development dependencies
```

The site is configured as a static multi-page Vite build and uses a relative asset base for deployment to GitHub Pages or another static host.
